☁️ Synchronisation cloud (optionnel)

Sans connexion, tout reste en local sur cet ordinateur (comme aujourd'hui). Avec un compte, vos données sont aussi sauvegardées dans le cloud et vous les retrouvez sur n'importe quel ordinateur.
⚙️ Configurer le cloud (une seule fois) — Supabase
Créez un projet gratuit sur supabase.com, puis collez ci-dessous l'URL du projet et la clé publique « anon » (Réglages → API dans Supabase).
