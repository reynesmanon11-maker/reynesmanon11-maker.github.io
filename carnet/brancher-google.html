Carnet de bord

Activer la connexion Google

Une seule fois, par la personne qui publie le Carnet — pas par chaque collègue. Une vingtaine de minutes, gratuit.

Avant de commencer

Le Carnet a besoin d'un identifiant Google : c'est lui qui permet à chacun de se connecter avec son propre compte, de lire son agenda Pronote et d'y écrire ses cours. Cet identifiant se crée dans la console Google Cloud, avec le compte Google qui « possédera » l'appli.

Les écrans de Google changent parfois de nom ; les liens ci-dessous mènent directement au bon endroit. Si la console est en anglais, le nom anglais est indiqué entre parenthèses.

  1. Créer le projet

    Ouvrir : nouveau projet

    Nom du projet : Carnet de bord , puis Créer. Vérifiez ensuite, en haut de la console, que ce projet est bien celui qui est sélectionné.

  2. Activer l'Agenda et Drive

    Google Calendar API Google Drive API

    Sur chacune des deux pages : Activer (Enable).

  3. Décrire l'appli

    Ouvrir : Google Auth Platform → Commencer (Get started)

    • Nom de l'application : Carnet de bord ; adresse e-mail d'assistance : la vôtre.
    • Audience : Externe (External).
    • Coordonnées : votre adresse. Acceptez les conditions, puis Créer.

  4. Image de marque

    Ouvrir : Branding

    • Page d'accueil de l'application : https://reynesmanon11-maker.github.io/carnet/
    • Règles de confidentialité : https://reynesmanon11-maker.github.io/carnet/confidentialite.html
    • Domaine autorisé : reynesmanon11-maker.github.io

    Puis Enregistrer. Pas de logo pour l'instant : en ajouter un demande une vérification par Google.

  5. Autorisations demandées

    Ouvrir : Accès aux données (Data Access) → Ajouter ou supprimer des niveaux d'accès

    Tout en bas, dans Ajouter manuellement (Manually add scopes), collez :

    openid
https://www.googleapis.com/auth/userinfo.email
https://www.googleapis.com/auth/calendar.calendarlist.readonly
https://www.googleapis.com/auth/calendar.events
https://www.googleapis.com/auth/calendar.app.created
https://www.googleapis.com/auth/drive.appdata

    puis Ajouter au tableau, Mettre à jour et Enregistrer.

    Ce que chacune permet, et ce qu'elle ne permet pas : voir la page de confidentialité.

  6. Qui peut se connecter

    Ouvrir : Audience → Utilisateurs test (Test users) → Ajouter des utilisateurs

    Votre adresse Gmail d'abord, puis celles des collègues qui essaient (100 au plus). Laissez l'appli en test : l'ouvrir à tous demande une vérification par Google, plus tard.

  7. L'identifiant

    Ouvrir : créer un client

    • Type d'application : Application Web (Web application) ; nom : Carnet de bord
    • Origines JavaScript autorisées : https://reynesmanon11-maker.github.io
    • URI de redirection autorisés : https://reynesmanon11-maker.github.io/carnet/

    Puis Créer. Google affiche l'ID client, qui se termine par .apps.googleusercontent.com : copiez-le.

  8. Le donner au Carnet

    Envoyez l'ID client à Claude, qui l'installe. Ou collez-le vous-même, entre les apostrophes de la ligne googleClientId: '' du fichier config.js, puis validez (Commit changes) :

    Ouvrir config.js sur GitHub

    Cet identifiant n'est pas secret : une appli web le montre forcément. Ce qui protège, c'est la liste des origines autorisées de l'étape précédente.

  9. Essayer

    Deux minutes plus tard, ouvrez le Carnet : le bouton Avec mon compte Google est actif. Tant que l'appli n'est pas vérifiée, Google affiche l'adresse du site au lieu de son nom, puis prévient qu'il ne l'a pas validée : Paramètres avancés, puis Accéder à … (non sécurisé), et cochez toutes les autorisations.
